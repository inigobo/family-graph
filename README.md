# Family Graph

A local-first family tree browser built around floating nodes. One person maintains a private family dataset and explores it with React, TypeScript and react-force-graph-2d.

## Local graph starter

Install Node.js 22 LTS, run `npm install`, then `npm run demo`. The demo opens an embedded LadybugDB file, seeds fictional records and looks up a grandparent by traversing two PARENT_OF edges.

## Roadmap

Start with persistent people, parenthood and partnership, one CSV importer and an interactive canvas. Explore sibling clusters, directional generation layouts and GEDCOM after the first version. Keep all personal imports, exports and database files under data/ or private/.
